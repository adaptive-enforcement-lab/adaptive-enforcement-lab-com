# Tombstone Markers

!!! note "What are Tombstone Markers?"
    Tombstone markers are a data management pattern used to indicate that an item
    has been deleted, without physically removing it immediately. This approach
    is common in distributed systems to manage eventual consistency, replication,
    and prevent resurrection of deleted data during synchronization.
