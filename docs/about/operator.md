# The Operator

!!! info "A Personal Brand"

    Adaptive Enforcement Lab is a personal brand. It is the kind of company I want to represent: security enforced by the pipeline, not promised in a policy document.

This page is the backdrop: what I build in the open, where I speak, and where I learned to lead.

## Open Source and Security

- **[private-pki-operator](https://github.com/adaptive-enforcement-lab/private-pki-operator)**: a Kubernetes operator and Helm charts for a private cert-manager PKI hierarchy, with zero-downtime root CA rotation. MIT licensed. I offered it to cert-manager in [discussion #8472](https://github.com/cert-manager/cert-manager/discussions/8472).
- **[agentgateway](https://github.com/agentgateway/agentgateway/pulls?q=is%3Apr+author%3Amarkcheret)**: a fix that keeps mid-conversation system messages in place on Vertex Gemini.
- **[SecObserve](https://github.com/SecObserve/SecObserve/issues/5019)**: an OIDC bug report, and security advisory [GHSA-h2w8-cwrc-rxmm](https://github.com/SecObserve/SecObserve/security/advisories/GHSA-h2w8-cwrc-rxmm), which credits me as reporter.
